# Project: Autonomous Agentic Game Studio & Observability Platform

## Architecture
The system is an autonomous, requirement-driven multi-agent game studio swarm that scans a player's Steam library, extracts their behavioral `SteamPlayerDNA`, authors a comprehensive `GameRequirementsSpec`, and iteratively conceives, illustrates, voice-acts, codes, instruments, and verifies complete, original **Godot 4.3** (and Pygame) games—persisting all telemetry, studio events, task records, and requirement progress in **SQLite WAL** (`data/telemetry.db`).

### Core Modules & Responsibilities
- `engine/studio/`: Orchestration and specialist agents.
  - `orchestrator.py`: Meta-planning DAG, continuous multi-slice Production Board progression (`Slice 0..N` with clean roadmap-completion termination), immutable flag-safe checkpointing (`_clear_immutable_and_writable`, `cartridges/checkpoints/`), and iterative requirement-by-requirement (`R1..Rn`) execution loop.
  - `models.py`: Epistemic data models (Pydantic models inheriting from `BaseEpistemicModel` with `deliberation` strictly at field index 0).
  - `director.py`: Concept (`GenesisWorldSpec`) & Game Requirements (`GameRequirementsSpec`) authoring from `SteamPlayerDNA` / `EvolutionHypothesisReport`.
  - `writers_room.py`: Hierarchical `CreativeWritersRoom` (`CORE_COUNCIL_ROSTER` + `SUBAGENT_ROSTER`) that runs **Emergent Concept Genesis** (`pitch_and_greenlight_concept`), builds the Living Game Bible (`GameBibleSpec`) with an upfront 16:9 Concept Art Mockup, iterative `slice_roadmap` (`GameSliceSpec`, `_run_end_of_slice_blind_playtest` with 5-frame filmstrip + chronological action tape skeptical audit and per-pass `blind_playtest_report_<slice_id>_pass<k>.json` archival, `BlindPlaytestCouncilTurn`, `BlindPlaytestCouncilVerdict`, `_run_slice_qa_gate_check` spawning tracked `qa_gate_pass*` `ProductionBoard` remediation tasks on 5-gate failure, `_run_slice_reflection_and_strategy`, `NextSliceStrategyPlan`, `run_slice_expansion`), `technical_architecture_blueprint`, and `rendering_strategy` (`RenderingStrategySpec`), ensures all essential domain specialists contribute (`_missing_required_board_specialists`), authors and dependency-orders the unified `production_backlog` (`WorkItem` DAG), conducts multimodal Specialist Review & Council Cap Moderation (`_review_as` with `qa_test_script_source` and runtime telemetry visibility, `CapDecision`, `escalate_failed_to_decision`), and executes multi-specialist live Executive Producer steering and manual playtest report dispatch (`_execute_steering_pivot_turns`, `_consume_pending_playtest_wishes`).
  - `context_curator.py`: Semantic Context Curator Agent (`CartridgeSemanticIndex` + `ContextCuratorAgent`) that extracts granular `ContextChunk` records across concept art mockups, catalog sprites (`hframes`, `vframes`, `tex_size`), catalog `.wav` audio assets (`duration_seconds`, `perceptual_description`), Council utterances, rendering treatments, Production Board items, active per-game long-term memories (`memory:<bank>:<memory_id>` with proactive bank isolation across `"council"`, target role's bank, and `applicable_roles`, plus `memory_sig` cache invalidation), build execution traces (`board:trace:<item_id>` from `lead_trace_rev*.json` with turn deliberations, `code_diffs`, and `.telemetry.json` per-frame coordinate trajectories), and GDScript code modules (`const` declarations, `KEY_*` input bindings, `collision_layer`/`CanvasModulate` semantics, and a 3-hop bidirectional reference graph), caches Gemini embeddings by SHA-256 (`artifacts/context_index.json`), inspects multimodal proof artifacts during curation, curates revision- and intra-revision-scoped (`intra_rev_sig`) context packs (`artifacts/work_items/<item_id>/context_pack_<role>.json`) strictly from LLM-selected `selected_chunk_ids` and `selected_media_paths` (`.png` mockups/plates/filmstrips, `.wav` audio cues, and `.mp4` audiovisual clips), and powers persistent agent self-inquiry (`self_question` -> `research_question_context` -> `self_question_answer`).
  - `game_memory.py`: Thread-safe per-game multi-bank long-term memory system (`GameMemoryStore`, `<cartridge_dir>/game_memory.json`, mirrored to `studio_game_memories` in SQLite WAL, copied into verified checkpoints, and rehydrated in `daemon.py`) partitioned across `"council"` and 16 specialist role banks (`CANONICAL_MEMORY_BANKS`), supporting `gemini-embedding-001` semantic `query_memories`, lifecycle mutations (`record`, `update`, `fulfill`, `supersede`, `archive`), default-empty Counterfactual Durability gating, and vector cosine-similarity deduplication (`MEMORY_DEDUP_COSINE_THRESHOLD = 0.86`, SHA-256 cached in `artifacts/memory_embeddings.json`).
  - `production_board.py`: Continuous `ProductionBoard` DAG scheduler and granular per-file lock table (`FileLockTable`) that claims unblocked `WorkItem` tasks across concurrent workers (prioritizing interrupted tasks with prior execution history via `has_prior_execution_activity` and syncing disk trace attempt counts via `_sync_attempt_counts_locked`), preserves `changes_requested` across `requeue_failed` when Council revision feedback exists, rejects production proposals targeting `tests/` harness files, tracks `waiting_on_locks` for parallel GDScript submodule edits, prioritizes parallel asset tasks when locks are busy, supports dynamic prerequisite task spawning (`spawn_tasks_from_item`, `wait_for_spawned_tasks`), cooperative non-blocking `WorkerYielded` task yielding (`yield_item`) with turn-level resumption, and escalation of repeated worker failures (`escalate_failed_to_decision`).
  - `workers.py`: Iterative Task Lead Strategist (`run_task_lead`) and 6 autonomous domain specialists (`visual_artist`, `audio_designer`, `audio_evaluator`, `script_writer`, `swe_engineer`, `qa_test_engineer`). Every board task runs through `run_task_lead` (`current_strategy` + `proof_strategy`) with SHA-256 ground-truth disk diff tracking (`touched_files` / `untouched_target_modules`), supporting dynamic task spawning (`action="spawn_tasks"`), generic multi-cell grid/atlas asset planning (`grid_cols`, `grid_rows`, `cell_prompts`), modular GDScript submodule authoring (`scripts/*.gd`, `CodeImplementationPlan.module_path`, `code_diffs`), isolated QA test scene synthesis (`FilmstripPlan.test_scene_gd_content` -> `res://tests/test_<item_id>.tscn`), synchronized audiovisual clip proof capture (`FilmstripPlan.record_audiovisual_clip`), structured QA production defect reporting (`FilmstripPlan.production_defect_report`), in-turn self-correction when `swe_engineer`/`qa_test_engineer` raises an error, multimodal Task Lead proof inspection (`_build_task_lead_multimodal_parts` across `.png`, `.wav`, and `.mp4`), uncapped active-turn step/epistemic prompt telemetry (`record_turn_substep`, `record_turn_epistemic_context`), and persistent turn-level yield/resume (`lead_trace_rev{N}.json`).
  - `proofs.py`: Multimodal proof rendering (`capture_filmstrip` and optional `capture_audiovisual_mp4` at `--fixed-fps 60`, `render_level_map`, `render_waveform_image`, `render_script_sheet_image`) producing task-ID-scoped inspection artifacts (`filmstrip_{item_id}_rev{rev}.png` with distinct `[QA]` slate contact-sheet margins and 1px viewport borders, plus optional `audiovisual_{item_id}_rev{rev}.mp4`), counterfactual zero-input verification, and `.telemetry.json` runtime observability (`visible_ui_texts`, `audio_players_detail`, and `main_scene_parity`).
  - `rendering.py`: Per-game `RenderingStrategySpec` validation, hybrid procedural + generated visual helpers (`StudioRigHelper.create_tiled_polygon` for tiling seamless `tile_surface` PNGs across procedural `Polygon2D` contours), and Godot 4.3 rendering/shader/post-process synthesis.
  - `sfx_synth.py`: Parametric multi-layered DSP sound effects synthesizer (`SFXLayerSpec`, `SFXPatchSpec`) with ADSR envelopes, filter sweeps, FM/ring modulation, pitch envelopes, and resonator banks.
  - `swe.py`: Iterative multi-module Godot 4.3 GDScript (`project.godot`, `main.tscn`, `main.gd`, `scenes.gd`, `mechanics.gd`, `entities.gd`, `ui_hud.gd`) and Python code synthesis, unread `summarized_only_mods` overwrite guard (`_validate_no_large_file_clobber` -> `self_question`), per-task `allowed_files`-scoped Godot compiler verification, upfront production strategy (`formulate_production_strategy`), per-scene multimodal critique & iterative refinement (`analyze_scene_and_restrategize`, `execute_scene_strategy_and_refine_loop`), atomic work-unit decomposition and Godot test synthesis (`decompose_track_into_atomic_units`, `synthesize_atomic_godot_test`), and 2-hop scoped Plan-Execute-Verify surgical patching (`debug_and_patch_pev_cycle`) via `LeadGameplaySWEAgent`.
  - `asset_library.py`: Concept-grounded asset catalog (`CartridgeAssetLibrary`, `assets/asset_library.json`) with concept decomposition (flat structured-output schema, engineer-requested assets), recursive indexing across `assets/sprites/`, `assets/tiles/`, `assets/backgrounds/`, `assets/ui/`, and `assets/audio/` (`.wav` `duration_seconds` + `perceptual_description` via `update_audio_perceptual_description`), portrait-vs-world-sprite separation, and baseline asset derivation from the Game Bible.
  - `visual.py`: Gemini sprite, portrait, and tile synthesis via `VisualArtSpriteDesignerAgent`: single-subject base pose prompting, multi-tone perimeter flood-fill alpha matting (handling both chroma backdrops and 2-tone transparency checkerboards) + `rembg` + morphological single-subject isolation (`extract_clean_alpha_sprite`), continuous UV-displacement keyframe animation (`cv2.remap`), non-mirrored toroidal tiles, and Tier 1 / Tier 2 vision verification (`verify_rendered_asset`, `verify_rendered_animation`) that fail fast with `StudioAgentError`.
  - `audio.py`: Dynamic Gemini TTS `.wav` voice and sound synthesis (`VoiceActingAudioProducerAgent`).
  - `audio_evaluator.py`: Perceptual multimodal audio & audiovisual evaluator (`AudioEvaluatorAgent`) using `gemini-3.8-flash` via the Gemini Interactions SDK (`client.interactions.create`, wrapped by `install_studio_gemini_guardrails` and `TokenUsageTracker` / `PlaytestTokenTracker`), transporting `.wav`/`.mp4` media inline (`<= 18 MB`) or via `client.files.upload` + cleanup (`> 18 MB`), returning rationale-first `AudioEvaluationReport` critiques, enriching `asset_library.json` (`perceptual_description`), and enforcing strict opaque-box studio context isolation when `curate_studio_context=False`.
  - `narrative.py`: Narrative bible, character sheets, dialogue trees, and situational barks (`NarrativeCharacterWriterAgent`).
  - `telemetry_architect.py`: Custom behavioral telemetry probe design (`telemetry_manifest.json`) and GDScript/Python AST instrumentation (`TelemetryArchitectAgent`).
- `engine/supervisor/`: Verification, QA playtesting, and Game Designer signoff.
  - `supervisor.py`: `BuildSupervisor` executing Quality Gates A–F, `build_qa_gate_work_item_proposal` converting 5-gate slice failures into tracked `ProductionBoard` remediation tasks, and closed-loop self-healing before atomic promotion to `cartridges/active/`.
  - `challenger.py`: Gate F (`ChallengerGate` & `MultiAgentSignOffCouncil`) auditing 100% of acceptance criteria in `requirements_spec.json` plus camera/terrain perspective alignment, psychoacoustic comfort (zero continuous high-pitched looping sine/square wave drones), runtime audio stream binding (`AudioStreamWAV`), HiDPI-exact mouse picking (`get_global_mouse_position()`), non-occluding HUD panels (`center_occluding_panels`), and player onboarding clarity.
  - `models.py`: Verification models and `RejectionDiagnosticTrace` schema.
- `engine/sim/`: Headless simulation, real GPU viewport capture, and runtime scene auditing.
  - `godot_verifier.py` & `godot_harness.gd`: Headless Godot 4.3 compiler verification (`verify_godot_cartridge_syntax`), real GPU OpenGL3 viewport capture (`GodotHeadlessSimulator`, `_validate_rendered_viewport_image`), synchronized `--record-audiovisual` RGB + PCM capture and `ffmpeg` H.264 + AAC muxing (`mux_raw_rgb_and_pcm_to_mp4`, `capture_audiovisual_mp4`), live scene-tree UX/audio audit (`_audit_scene_tree`), collision-overlay capture, and `[TELEMETRY_EVENT]` bridge into SQLite WAL.
  - `atomic_runner.py`: `GodotAtomicTestRunner` executing `tests/test_*.gd` headless SceneTree unit tests (`[ATOMIC_ASSERT_PASS]` / `[ATOMIC_ASSERT_FAIL]`) and rendering `playtest_collision_overlay.png`.
  - `simulator.py` & `headless.py`: Headless Pygame simulation runner (`SDL_VIDEODRIVER=dummy`, `SDL_AUDIODRIVER=dummy`).
- `engine/playtest/`: Decoupled Blind Playtester Agent, Godot 4.3 interactive runner bridge, per-game/slice session archive, experience report synthesis, and broadcast video compositor.
  - `agent.py` & `models.py`: Zero-leak `BlindPlaytesterAgent` (`BlindStoreCard`, `PlaytestTurnDecision`, `PlaytestAudioEvaluationRequest`, `PlaytestRulebookUpdate`, `PlaytestImpressionUpdate`, `PlaytestFieldNoteUpdate`, `PlaytestQuestionUpdate`, `PlaytestBugReport`, `PlaytestCompactedJournal`, `PlaytestExperienceReport`, `PlaytestWishDraft`, `PlaytestReportDispatchRequest`) playing verified checkpoints solely from viewport screenshots and in-game audio (plus optional on-demand `2..20s` rolling gameplay clip evaluations queued via `queue_audio_evaluation_result`), enforcing sparse genuine-shift mood updates, maintaining byte-0 prefix caching across `30`-turn compactions, and synthesizing end-of-session player experience reports (`generate_experience_report`).
  - `godot_bridge.py` & `godot_playtest_runner.gd`: Live interactive Godot 4.3 playtest session bridge executing `0..1000` normalized screen-coordinate smooth cursor trajectories + desktop mouse parity (`Viewport.push_input`, custom-cursor-aware pointer overlay), capturing synchronized viewport frames + audio slices, extracting pure `1280×720` rolling lookback `.mp4` gameplay clips (`extract_recent_gameplay_clip_mp4`), and muxing `1600×720` side-by-side HUD broadcast MP4s (`replay.mp4`).
  - `session_manager.py`: Background session lifecycle orchestration (`PlaytestSessionManager`, `run_council_slice_playtest`, opaque-box `AudioEvaluatorAgent` lookback dispatch with `curate_studio_context=False`, `list_enriched_sessions` with `game_run_number` / `slice_run_number` / `games_catalog` / `report_sent_to_council_at_utc`, `record_council_verdict`, cartridge-level `session_archive.json` + automatic SQLite recovery, `1280×720` `action_px` denormalization, `confirm_delete`-guarded historical `reset`, `_recover_unmuxed_session_video`), SQLite WAL persistence (`playtest_sessions`, `playtest_turns`, `playtest_compactions`, `playtest_wishes`), strict `initiated_by` (`council` vs `operator`) wish-delivery gating, Council wish forwarding, and 1-click full manual playtest report + screenshots + wishes dispatch (`dispatch_session_report_to_council`).
- `engine/telemetry/`: Continuous SQLite WAL persistence.
  - `db.py`, `schema.sql`, `schema.py`, `recorder.py`, `writer.py`: Zero-lock SQLite WAL storage (`data/telemetry.db`) for `studio_events`, `agent_task_records`, `studio_requirements`, `studio_state_kv`, `studio_game_bibles`, `studio_game_memories`, `playtest_sessions`, `playtest_turns`, `playtest_compactions`, `playtest_wishes`, `telemetry_probes`, and `custom_telemetry_events`.
- `engine/ui/` & `studio-web/`: Mission Control Web Observability UI.
  - `server.py`: Starlette WebSocket & REST API server (`SwarmEventBus` with cross-process SQLite WAL live tailing over `/ws/swarm` & `/ws/stream`), live phase observability (`writers_room_activity`, `agent_activity`, `board_activity`), Long-Term Game Memory endpoints (`GET` / `POST /api/studio/memories`), Playtest Session Archive, Media, Wish & Full Report Council Dispatch endpoints (`/api/playtest/sessions`, `/api/playtest/sessions/{id}/send-report-to-council`), and SPA static/dev routing (`studio-web/dist/` or `STUDIO_WEB_ORIGIN`).
  - `studio-web/`: Modular React 19 + TypeScript + TanStack Query Mission Control single-page application featuring `TopCommandBar`, `SliceSubbar`, `LiveActivityBanner` (live phase observability across board & post-board gates), `useSwarmSocket` (immediate REST status reconciliation on WebSocket reconnect), and 7 integrated workspaces: **Production Board**, **Writers' Room**, **Game Bible**, **Game Memory** (`GameMemoryView.tsx`), **Assets & Code**, **Playtest Lab** (`PlaytestLabView.tsx` + `playtestNotebook.ts` with Current Focus banner, DVR Replay-to-Live scrubber, Activity Log `<details>`, structured Rulebook/Questions/Bugs, and Full Report Dispatch to Council), and **Player DNA**.

## Interface Contracts

### 1. `GameRequirementsSpec` Contract
- Location: `engine/studio/models.py`
- Inherits: `BaseEpistemicModel`
- Fields:
  - `deliberation: str = Field(..., description="Epistemic rationale analyzing player DNA, genre feasibility, and required systems")`
  - `game_title: str`
  - `genre_paradigm: str`
  - `target_audience_summary: str`
  - `requirements: list[RequirementTrack]`
  - `asset_manifest: list[AssetRequirement]`

### 2. `ChallengerGateEvaluation` & Game Designer Signoff Contract
- Location: `engine/supervisor/models.py` & `engine/supervisor/challenger.py`
- Inherits: `BaseEpistemicModel`
- Fields:
  - `deliberation: str = Field(..., description="Multi-perspective engineering & Game Designer UX critique evaluating candidate against every acceptance criterion and human playability mandate")`
  - `candidate_id: str`
  - `overall_verdict: bool` (`True` = PASS, `False` = REJECT)
  - `evaluated_requirements: list[RequirementEvaluationRecord]`
  - `rejection_trace: Optional[RejectionDiagnosticTrace] = None`

### 3. Swarm Event Bus & SQLite WAL Contract
- Location: `engine/ui/models.py`, `engine/ui/server.py`, `engine/telemetry/schema.sql`
- SQLite WAL Tables (`data/telemetry.db`):
  - `studio_events`: Stores all swarm events (`REQUIREMENTS_SPEC_GENERATED`, `REQUIREMENT_STATUS_UPDATE`, `QA_GATE_RESULT`, `CHALLENGER_GATE_VERDICT`, `CARTRIDGE_PROMOTED`, `CHECKPOINT_SAVED`, `AGENT_STREAM`) tailed live by `/ws/swarm` and `/ws/stream`.
  - `agent_task_records`: Stores per-task execution records, deliberations, verification verdicts, and `ArtifactMetadataEnvelope` handoffs.
  - `studio_requirements`: Stores per-track requirement status and acceptance criteria progress.
  - `studio_state_kv` & `studio_game_bibles`: Stores serialized `world_spec`, `requirements_spec`, and `GameBibleSpec` state.
  - `studio_game_memories`: Mirrors per-cartridge multi-bank long-term memory entries (`memory_bank`, `author_role`, `kind`, `status`, `title`, `content`, `applicable_roles_json`, `slice_id`, `item_id`, `resolution_note`, `superseded_by_id`).
  - `playtest_sessions`, `playtest_turns`, `playtest_compactions`, `playtest_wishes`: Stores blind playtester session lifecycles, multimodal turns, compacted journals, and triaged player wishes.

## Code Layout
- `engine/godot_runtime.py`: Portable Godot 4.3 runtime resolution and headless/windowed execution wrapper.
- `engine/playtest/`: Decoupled `BlindPlaytesterAgent`, `GodotPlaytestBridge` (`godot_playtest_runner.gd`), and `PlaytestSessionManager` broadcast video compositor.
- `engine/sim/godot_harness.gd`: Headless Godot 4.3 scene-tree auditor (`_audit_scene_tree`), exploratory input driver, and telemetry bridge.
- `engine/sim/godot_verifier.py`: Godot 4.3 stderr compiler parser (`parse_godot_stderr`, `verify_godot_cartridge_syntax`) and `GodotHeadlessSimulator`.
- `engine/studio/context_curator.py`: `CartridgeSemanticIndex` & `ContextCuratorAgent` with SHA-256 embedding cache, bank-isolated `game_memory` indexing, and persistent self-inquiry.
- `engine/studio/game_memory.py`: Thread-safe `GameMemoryStore` (`game_memory.json` + SQLite WAL + `gemini-embedding-001` semantic retrieval and deduplication).
- `engine/studio/director.py`: Concept (`GenesisWorldSpec`) & Requirements (`GameRequirementsSpec`) authoring.
- `engine/studio/writers_room.py`: Hierarchical `CreativeWritersRoom`, Emergent Concept Genesis, slice reflection/expansion, backlog review, and live steering.
- `engine/studio/production_board.py`: Continuous `ProductionBoard` DAG scheduler, `FileLockTable`, and parallel specialist dispatch.
- `engine/studio/workers.py`: Iterative Task Lead Strategist (`run_task_lead`) and 6 autonomous domain specialists (`visual_artist`, `audio_designer`, `audio_evaluator`, `script_writer`, `swe_engineer`, `qa_test_engineer`).
- `engine/studio/proofs.py`: Task-ID-scoped multimodal proof rendering (counterfactual filmstrips, synchronized `.mp4` audiovisual clips, runtime UI/audio/parity telemetry, level maps, waveforms, script sheets).
- `engine/studio/rendering.py`: Per-game `RenderingStrategySpec` validation and Godot 4.3 rendering/shader synthesis.
- `engine/studio/sfx_synth.py`: Parametric multi-layered DSP sound effects synthesizer (`SFXPatchSpec`, `SFXLayerSpec`).
- `engine/studio/audio_evaluator.py`: Perceptual multimodal audio & audiovisual evaluator (`AudioEvaluatorAgent`, `gemini-3.8-flash` Interactions SDK, `AudioEvaluationReport`, `perceptual_description` catalog enrichment).
- `engine/studio/orchestrator.py`: Swarm DAG, continuous production board driver, and checkpoint manager.
- `engine/studio/swe.py`: Multi-module GDScript 4.3 / Python synthesis and holistic self-healing (`repair_godot_cartridge_holistic`).
- `engine/studio/visual.py`: Live Gemini pixel-art sprite & portrait generator with background-to-alpha transparency.
- `engine/studio/audio.py`: Live Gemini TTS voice & sound generator + parametric DSP SFX synthesis.
- `engine/supervisor/challenger.py`: Gate F Adversarial Design Critic & Game Designer Signoff (`CandidateASTInspector`, `ChallengerGate`).
- `engine/supervisor/supervisor.py`: 6-Gate `BuildSupervisor`, `build_qa_gate_work_item_proposal` tracked QA board remediation, and self-healing loop.
- `engine/ui/server.py`: Starlette WebSocket & REST API server (`SwarmEventBus`, SQLite WAL live tailing, `studio-web/dist/` SPA serving).
- `studio-web/`: Modular React 19 + TypeScript + TanStack Query Mission Control SPA (`src/features/shell`, `board`, `writers-room`, `bible`, `memory`, `assets`, `playtest`, `dna`).
- `run_studio.py`: Studio Mission Control server & daemon entrypoint.
- `run_game.py`: Native 60 FPS game & checkpoint launcher.
